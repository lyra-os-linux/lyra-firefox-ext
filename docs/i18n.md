# Idiomas da integração 0.1.3

Os catálogos en-US, pt-BR e es-ES cobrem a interface, notificações e recuperação
do repasse. O Firefox seleciona o idioma; o fallback do manifesto é en_US.
O atributo lang das páginas acompanha o catálogo efetivamente exibido.

Erros do native host usam códigos estáveis para selecionar mensagens no idioma
do navegador, independentemente do idioma do serviço. Detalhes da falha ficam
disponíveis no aplicativo. Mensagens de histórico persistidas anteriormente
conservam o texto original; a atualização não modifica o estado das transferências.

`npm test` verifica cobertura, placeholders, referências das páginas e tradução
dos códigos nativos, além das regressões de repasse e recuperação. `npm run lint`
valida o pacote WebExtension. Em 21/09/2026, perfis descartáveis do Firefox real
passaram em en-US, pt-BR, es-ES e francês (fallback inglês), com o código local
instalado temporariamente. Esse ensaio não substitui a verificação do XPI assinado
nem os testes da ISO candidata.

A versão 0.1.3 também aguarda por até 500 ms os metadados HTTP quando o Firefox
entrega `downloads.onCreated` antes de `webRequest.onSendHeaders`. Só metadados
reais liberam a decisão; ausência, POST e autenticação continuam sujeitos às
mesmas recusas. O ensaio reproduziu a ordem invertida também na versão 0.1.1.
